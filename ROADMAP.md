# Roadmap and Milestone Gates

## M0 — Governance and proof of architecture

Exit:

- durable specs and ADR process
- validated Codex harness
- repo/CI skeleton
- product domain model
- Saju methodology v1 draft
- privacy and threat model
- issue backlog with dependencies

## M1 — Local vertical slice

Exit:

- account/profile/birth input
- deterministic chart calculation
- basic candidate discovery
- like/match
- basic Gung-hap explanation from structured rules
- report/block/unmatch
- critical local E2E

## M2 — Staging

Exit:

- reproducible staging
- managed DB/storage/auth
- chat
- moderation console/workflow
- observability
- privacy export/delete
- CI/CD and migration workflow
- staging smoke tests

## M3 — Private alpha

Exit:

- verified invited users
- safety operations coverage
- curated Inyeon Match
- event taxonomy and KPI dashboard
- controlled feedback loop

## M4 — Production-ready city beta

Exit:

- production infra + backups/restore
- verification approach
- subscriptions if enabled
- full Gung-hap report
- post-date feedback
- penetration/threat-model review findings addressed or gated
- legal/policy review completed by humans

## M5 — Production launch

Exit:

- DNS/TLS/production runtime
- prod migrations
- signup/discovery/match/chat/report/delete verified
- alerts and error tracking
- release/rollback runbook
- support/moderation SLA ownership
- production smoke tests green

## M6 — Operate and improve

Loop:

`OBSERVE → TRIAGE → ACT → VERIFY → LEARN`

Optimize safety and meaningful connection quality before vanity engagement.
